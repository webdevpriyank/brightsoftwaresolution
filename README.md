# brightsoftwaresolution

Website for **Bright Software Solution** — https://brightsoftwaresolution.in
WhatsApp Business API platform · Software development · ERP · Design · Digital marketing · Infrastructure.

```text
website/   Deployable site (upload the contents to Hostinger public_html)
build/     Static site builder + SEO / SEM / AI-search playbook (build/README.md)
logo/      Original brand logo files
```

## Build

```bash
node build/build.mjs      # regenerate pages, sitemap, robots.txt, llms.txt (Node 18+, no dependencies)
node build/indexnow.mjs   # after deploying: notify Bing / ChatGPT search / Copilot
```
